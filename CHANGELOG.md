# Changelog

## 1.0.0 (2026-11-16)

First public release.

- Engineering plugins `ship`, `check`, `crew`, `server`, `web`, `mobile`, `kit`, `guard`: restructured and rewritten from ai-engineering-skills (MIT). New skill shape with `model`/`effort` per skill, "Use it when / Before you start / Steps / Done when / Never / Next" sections, a solo shortcut, and lighter dependencies (`server`, `web`, `mobile` need only `check`).
- `linkedin`, `ads`, `video`: my own skills for LinkedIn writing, ChatGPT Ads Manager and short video reels.
- `scripts/check.py` and `scripts/install-skills.sh`.
